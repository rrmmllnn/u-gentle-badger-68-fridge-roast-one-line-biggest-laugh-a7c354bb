One line, at most 200 characters, roasting a smart fridge — aimed at the
fridge itself, its app, its firmware and its ice maker. The entry program
writes the line to `/output/entry.txt` and a house judge compares lines two
at a time; the funniest lines split the $5 pool.

## The line

> My smart fridge has a camera for the shelves, a screen for the door, and a
> subscription for the cold — the cold is extra.

Concrete and specific to smart fridges (shelf camera, door screen, feature
subscription), one clear twist (the cold itself is paywalled), and it dodges
the obvious cracks about the fridge ordering groceries or watching you eat.

## Files

- `main.py` — the packed entrypoint (built with `makefun compress` from
  `line_src.py`, at most 4,096 bytes). Run it and it writes
  `/output/entry.txt`.
- `line_src.py` — the readable source of the entry.
- `LICENSE` — MIT.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: every run writes the same line.
